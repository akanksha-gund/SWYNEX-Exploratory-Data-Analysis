# Titanic Exploratory Data Analysis Project

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of the Titanic dataset using Python.

The analysis was performed to understand survival patterns, passenger characteristics, relationships between variables, and important trends in the dataset.

## Dataset

The analysis was performed using the cleaned Titanic dataset from Task 1.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Exploratory Data Analysis Performed

### 1. Survival Analysis

Analyzed overall survival rates and explored patterns related to passenger survival.

### 2. Gender and Passenger Class Analysis

Compared survival patterns across gender and passenger classes.

### 3. Age and Fare Analysis

Analyzed the distribution of passenger ages and fares and examined their relationship with survival.

### 4. Embarkation Analysis

Analyzed passenger distribution and survival patterns based on embarkation port.

### 5. Family-Size Analysis

Examined the relationship between family size and passenger survival.

### 6. Correlation Analysis

Created a correlation heatmap to understand relationships between numerical variables.

### 7. Outlier Analysis

Identified potential outliers in numerical variables such as age and fare.

### 8. Data Visualization

Created multiple charts and visualizations to communicate important patterns and trends.

## Key Insights

- Survival rates varied across passenger groups.
- Gender and passenger class showed noticeable differences in survival.
- Age and fare distributions revealed important patterns in the dataset.
- Family size had a relationship with survival outcomes.
- Correlation analysis helped identify relationships between numerical variables.
